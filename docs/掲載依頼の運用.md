# 掲載依頼・削除依頼の運用

実在のアイドルは、本人または所属運営から依頼があり、確認がとれた人だけを `idols.js` の `LISTED_IDOLS` に載せる。

## Google フォームの作り方

1. Google フォームを新規作成し、タイトルを「女ヲタヲタシミュレータ 掲載・削除のご依頼」にする。
2. 設定 → 回答 → 「メールアドレスを収集する」をオン（返信と本人確認に使う）。
3. 下の質問を作る。
4. 「送信」→ リンクをコピーし、`idols.js` の `REQUEST_FORM_URL` に貼って push する。

### 質問の案

| # | 質問 | 形式 | 必須 |
|---|---|---|---|
| 1 | ご依頼の種類 | ラジオ：掲載 ／ 掲載内容の変更 ／ 削除 ／ 架空アイドルの名前が実在の方と重なっている | ○ |
| 2 | ご依頼者 | ラジオ：アイドル本人 ／ 所属事務所・運営 | ○ |
| 3 | アイドルのお名前 | 記述式 | ○ |
| 4 | グループ名 | 記述式 | ○ |
| 5 | 確認用の公式アカウント（X など）の URL、または運営の公式メールアドレス | 記述式 | ○ |
| 6 | 担当カラー | 記述式 | 掲載時 |
| 7 | 載せてよい追加情報（活動拠点・ジャンル・誕生日・特典会のようす） | 段落 | |
| 8 | 掲載内容への同意 | チェック：「推しとしてお名前が表示され、ヲタヲタ場面（つきまとい・出禁などの風刺）にも推しとして出ることがあると理解しました」 | 掲載時 |
| 9 | その他・ご連絡 | 段落 | |

## 掲載の手順

1. フォームの回答を見る。
2. 本人確認をとる：5 の公式アカウントに DM するか、公式メールに返信し、依頼が本物か確かめる。とれなければ掲載しない。
3. 8 の同意にチェックがあることを確認する。
4. その時点の X のフォロワー数を調べる。
5. `idols.js` の `LISTED_IDOLS` に1行足す（`from` と `listed` も書く）。
6. コミットして push する。公開ページに反映されたら、依頼者に掲載したことを連絡する。

## 削除の手順

1. 削除依頼は、いたずらと明らかなもの以外は本人確認を待たずに対応する（目安：7日以内）。
2. `idols.js` から該当の行を消し、コミットして push する。
3. 依頼者に削除したことを連絡する。
4. フォームの回答も削除する（about.html の「プライバシー」に書いた約束）。

## 架空アイドルの名前が実在の方と重なっていた場合

`index.html` の `NAMES`（メンバー名）または `GROUPS`（グループ名）を別の名前に変えて push する。

# 女ヲタヲタシミュレータ（風刺版）

男性アイドルオタクの15年を、リアルタイムで眺めるシミュレータです。推しはランダムに決まり、1年は3分・6分・9分から選んだ速さで勝手に進みます。

- 最初に名前、オタクを始める年、年齢、1年の速さを選ぶ
- 年のはじめに「今年の重点」（推し活・身だしなみ・仕事・人間関係）を選ぶ
- 年に2〜3回、現場での「女ヲタヲタ」な場面で行動を選ぶ
- ヲタヲタ度が低く、紳士度と清潔感が高いと出会いが訪れ、交際・プロポーズを経て結婚であがり
- ヲタヲタ行動を重ねると、出禁や界隈追放などのバッドエンド
- 推しは選べない。架空のアイドル名簿から「フォロワー数に比例／全員同じ確率／反比例」の確率で決まる。タイトルに「いま沼に落ちるとしたら」の確率ランキング
- 沼落ちは「整列 → 入場券のお目当てが回って止まる → 沼落ち届」の演出。推しが卒業すると推しロスを経て、別の現場で次の沼に落ちる。入場券の半券はエンディングに残る
- 一時停止・早送りあり、エンディング6種

## 実在アイドルの掲載

アイドルは基本的にすべて架空です。本人または所属運営から掲載依頼があり、確認がとれた人だけを `idols.js` に追加します。受付は `about.html`（このサイトについて）から。運用の手順とフォームの質問案は `docs/掲載依頼の運用.md` にあります。

## エピソードの追加

ヲタヲタエピソードは `episodes.js` にまとまっています。同じ形で項目を足せば、ゲームに自動で入ります。

## 遊び方

`index.html` をブラウザで開くか、GitHub Pages で公開した URL から遊べます。
